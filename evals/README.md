# Evals

The sample set behind YAH's checks and the README examples. Each file in `samples/` is one case: the prompt, what to check, the default output, and the YAH output.

## How the outputs were made

- **Default output:** the same model answering the prompt with no skill loaded and no style instructions.
- **YAH output:** the same model following `skills/yah/SKILL.md` and the reference files it points to, with no other writing skill active.

The 0.1.0 outputs were generated by Claude Opus 5.5 subagents on November 12, 2026, each case in a fresh context. The YAH agents were told to follow YAH's files instead of having the skill trigger on its own, so these runs test the instructions, not the triggering.

To re-run a case with the plugin loaded (untested so far, because headless `claude -p` wasn't logged in when 0.1.0 was built):

```bash
claude -p --disable-slash-commands "<prompt>"        # default
claude -p --plugin-dir . "Use the yah skill. <prompt>"  # YAH
```

Use `--resume` with the session id for the second turn of a multi-turn case.

## Checks per case

1. **Fact check (R.3, R.10):** list every fact in the prompt and in the output. An added specific (number, name, date, quote, source) fails. A dropped claim fails unless it was filler.
2. **Tell scan (R.13):** read the output against `skills/yah/references/tells.md` and record what's left.
3. **Case check:** the "What to check" line in each file.
4. **Blind read:** a reader sees both outputs in random order, without labels, and picks the one that reads as written by a careful person. Record the pick and the reason.

Re-run the whole set when a new model ships, and update the word lists in `tells.md` from what the default outputs show.
